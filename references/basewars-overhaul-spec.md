# Base Wars Overhaul — Design Spec

**Status:** Canonical design source for the Base Wars resource + terrain overhaul.
**Workload:** `nodecore` (Forge 1.20.1, profile `forge-mod-v1`).
**Authored:** 2026-06-20 · Orchestrator: Claude (Corwin) · Executor: Grok Build.
**Supersedes:** the AdLods / Large Ore Deposit LOD-mirroring approach (to be torn down).

---

## 0. Vision

Base Wars targets **large-to-massive servers (hundreds of players)**. The world is a **dead war-wasteland on the surface**; both **metal** and **life** must be *held* underground or out in the open, never freely mined. The economy is built on **renewable, contested resource points** — you don't mine resources out, you **control taps that produce over time**. This scales to hundreds of players because taps never run dry, so there is always territory worth fighting over.

Two pillars:
1. **Ore extractor nodes** — the metal economy (war over taps + logistics).
2. **Lush underground caverns** — the life/agriculture economy (war over farming strongholds).

Surface = dead. Everything that matters is held, defended, and supplied.

## 1. Ore Extractor Nodes (metal economy)

### 1.1 The node
- **Indestructible permanent world fixture.** Cannot be mined out, moved, or destroyed.
- Generated by a **new config-driven worldgen pass** that **replaces** the AdLods finite-deposit generator.
- **Metal types cluster geographically** — e.g. a copper region, an iron region. Controlling territory = controlling access to that metal. (Implementation: biome/region-keyed node-type selection, not uniform scatter.)
- **Tiers = richer output.** A tier-3 copper node out-produces a tier-1 copper node. Tiers are an *output-richness* axis, NOT a rarity-of-metal axis.

### 1.2 The extractor (multiblock)
- **One extractor per node.** The node is the singleton prize.
- Player-built **multiblock drill** attached to the node. Valid structure → it ticks → pumps that node's ore into an **output buffer**.
- **Raidable** — the extractor is the vulnerable investment. You contest a node by destroying the holder's extractor and placing your own. (The node itself is never destroyed.)
- **Output composition:** mostly processable ore, with the **occasional raw ore block** (less frequent).

### 1.3 Power & fuel
- **Drive: Create rotational power.** (Create is in the pack.)
- **Fuel = production-speed booster**, tiered by fuel item, ascending:
  `charcoal → coal → lava → Liquid Fire (top)`
  *(Note: charcoal/coal are equal burn time in vanilla; here each fuel maps to a distinct boost multiplier via config. Ladder direction confirmed ascending — Liquid Fire is the pinnacle. Charcoal-vs-coal exact ordering: pending final confirm, defaulting charcoal=entry, coal=next.)*
- **Lava can be piped in** for faster production (lava is a mid-ladder fuel).
- All boost multipliers + consumption rates **config-driven**.

### 1.4 Backpressure & decay (logistics enforcement)
- **Output buffer with backpressure:** buffer full → production **pauses** until hauled out.
- **Power loss → production pauses AND buffer very slowly decays.** Neglected/cut-off taps bleed out.
- Intent: **force real logistics** — protected haul lines, storage, mobile defense.

### 1.5 No-build aura (keystone mechanic)
- **No players building bases on or near nodes** → taps stay **exposed**, un-fortressable.
- Mechanism: a **no-block-placement aura** of **config-set radius** around each node that **whitelists only the extractor's own multiblock parts**. You can build the drill; you cannot wall it into a fortress.
- **Configurable:** radius, enable/disable toggle, and the whitelisted-block set.
- Design consequence: defense must be **mobile/remote + supply-line based**, not turtling on the tap.

### 1.6 Fallback economy (anti-starvation)
- Create processing (**grinding / washing / haunting**) is **kept but with severely reduced output**.
- This is the **baseline grind** the ~majority who don't hold a tap survive on. Holding a tap is the **multiplier**, not the only path. Nobody starves; taps are still worth dying over.

## 2. Lush Underground Caverns (life / agriculture economy)

- **Real worldgen** — MASSIVE lush caverns (lush-cave style), generated, not marker-stamped.
- **Only spawn below Y 0.**
- Naturally generate **surface flora underground**: **trees (via Dynamic Trees)**, grass, ferns, etc. — the full surface biome look, sealed in a giant cavern.
- Big enough to house **tree farms, crop farms**, etc.
- **Growth-tick booster** applied inside (see §4 — existence to be verified).
- **Contested / raidable like ore taps** — lush caverns are farming strongholds (food/resource power), fought over and raided, not neutral PvE havens.

---

## 3. Surface Grass — dead-world recolor

- Surface grass renders **uniformly dead-tan**. No green islands on the surface.
- Green life exists **only underground** in lush caverns (§2).
- Implementation: global grass-color/tint override (biome grass color provider).

---

## 4. Liquid Fire (custom fluid — top-tier fuel)

- **New Forge fluid + fluid block + bucket**, registered as a high-tier furnace/extractor fuel.
- **Creation:** place a **cauldron under soul sand with lava on top** → the cauldron **slowly fills with Liquid Fire** over time. (Passive collection block-interaction.)
- **Color/tint:** bright neon blue **`#00FBFF`** (matches soul fire).
- **Particles:** emit `ParticleTypes.SOUL_FIRE_FLAME` from the fluid block in-world (random display ticks).
- **Fuel value:** burn time **32000–40000 ticks** in the item registry (≈1.6–2× a lava bucket's 20000 — pinnacle fuel).
